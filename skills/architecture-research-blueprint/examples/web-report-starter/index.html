Module 02

Security & Zero-Trust Architecture

Service perimeters, identity delegation, and cryptographic protection across all layers.

🛡️

Security Invariants & Countermeasures

  • Zero-Trust Identity: Enforce Workload Identity Federation with short-lived tokens and zero service account key downloads.
  • Data Perimeter: VPC Service Controls (VPC-SC) isolate managed Google Cloud APIs from data exfiltration risks.
  • Encryption at Rest & Transit: Customer-Managed Encryption Keys (CMEK) with Cloud KMS, plus automatic TLS 1.3 across all hops.
