# Visual direction

Use a white sheet, charcoal text, thin neutral strokes and muted container fills.
Blue carries the primary journey; saturated accents signal focus. Dark surrounding
chrome is an optional booth treatment. Avoid decorative gradients, oversized logos
and shadows on every node. Icons identify products; words explain their role.

Use an 8-unit spacing rhythm, 16–24 units inside containers and generous routing
corridors. Align cards to a few columns. Equal importance gets equal treatment;
emphasize the main service through position and whitespace. Plan label space
before routing. Prefer fewer bends and crossings.

Use sans-serif for titles and descriptions, monospace for protocols and exact
configuration. Cards carry a title and subtitle; details belong in tooltips/notes.
Size for the delivery canvas: a 16-unit SVG label scaled to 0.5 is 8 screen px.
For 16:9 slides start around 32–40 pt titles and 18–24 pt diagram text. Split dense
views instead of shrinking text. On phones an overview can orient, but focused
views or accessible descriptions must carry readable detail.

## Hierarchy

1. One sentence states the slide's point.
2. The diagram occupies most of the space.
3. One journey or concern carries emphasis.
4. A compact legend explains lines and boundaries.
5. Sources and deeper explanation live in notes.

Keep colors stable across views. Pair color with labels or line styles. Label
functional groups as concerns and real boundaries by type. Never imply that a
functional grouping is a subnet or security boundary.

At thumbnail scale, the entry point and main path should be clear. At intended
screen size, labels should be readable without leaning forward. Inspect every
state after fonts load for balance, cramped corridors, competing accents and
clipping. Preserve component positions across related slides where possible.
